# ADR 001: Вендоринг ai-homework-mentor через editable path

**Статус:** Принято  
**Дата:** 2026-08-02  
**Автор:** Course Companion Team

---

## Контекст

Course Companion использует `ai-homework-mentor` как основной движок проверки домашних заданий. Необходимо было выбрать способ интеграции — mentor разрабатывается параллельно в том же монорепозитории и активно меняется.

## Решение

`ai-homework-mentor` вендорится как **editable path-dependency** в `pyproject.toml`:

```toml
[tool.uv.sources]
homework-mentor = { path = "../ai-homework-mentor", editable = true }
```

## Альтернативы

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **Editable path (выбрано)** | Изменения в ментор видны сразу без переустановки | Работает только в монорепо |
| Fork + поддержка | Полная независимость | Merge-налог при каждом обновлении upstream |
| PyPI-пакет | Стандартная зависимость | Требует публикации и версионирования |
| REST API (отдельный сервис) | Деплой независим | Оверкилл для CLI-инструмента |

## Последствия

**Позитивные:**
- Обновления в `ai-homework-mentor` немедленно доступны в companion без переустановки.
- Нет дублирования кода между проектами.
- `MentorOrchestrator` можно мокировать в тестах обычным `unittest.mock.patch`.

**Негативные:**
- Companion нельзя установить в изоляции от монорепозитория (нужен путь `../ai-homework-mentor`).
- В CI необходимо клонировать весь монорепозиторий, а не только `course-companion/`.
