# ADR 003: Один Companion с middleware вместо трёх отдельных агентов

**Статус:** Принято  
**Дата:** 2026-08-02  
**Автор:** Course Companion Team

---

## Контекст

Companion имеет три режима работы: `qa`, `homework`, `review`. У каждого свои промпт и набор доступных тулов. Необходимо выбрать архитектуру: один агент с runtime-адаптацией или отдельный агент на каждый режим.

## Решение

Один `Companion`-агент с **middleware** (`build_modes_middleware`). Переходы между режимами — через **тулы-переходы** (`switch_to_homework`, `complete_homework`, `return_to_qa`, `resubmit_homework`), которые возвращают `Command(update={"mode": ...})`.

```python
# Переход как тул-вызов:
def complete_homework(hw_artifacts, tool_call_id) -> Command:
    return Command(update={"mode": "review", "hw_artifacts": hw_artifacts, ...})
```

## Альтернативы

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **Один агент + middleware (выбрано)** | Единая история диалога; переход = тул-вызов | Middleware сложнее изолированного агента |
| Три отдельных агента с handoff | Полная изоляция логики режима | История диалога обрывается при смене агента; тройной оверхед компиляции |
| Агент + роутер переключает агентов | Изоляция + роутер | Нет общей истории; нужен механизм передачи контекста |

## Обоснование

Единая история диалога — ключевое требование продукта: студент задаёт вопросы, сдаёт ДЗ и разбирает фидбек в одном чате без сброса контекста. При смене агента история теряется либо требует явной передачи, что усложняет архитектуру без выгоды.

Middleware — лёгкий механизм: `select_prompt(mode)` + `filter_tools(mode, tools)` вызываются при каждом шаге агента. Blacklist-подход (запрещаем явно ненужные тулы) предпочтительнее whitelist — новый тул виден во всех режимах по умолчанию.

## Последствия

- История диалога сохраняется через все режимы.
- Middleware тестируется отдельно от агента.
- `InjectedState` в тулах (`explain_feedback`, `show_fix_plan`) позволяет читать `hw_artifacts` без глобального состояния.
- При добавлении нового режима нужно обновить `MODE_PROMPTS` и `MODE_TOOL_BLACKLIST` в `middleware.py`.
