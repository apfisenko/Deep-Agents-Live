# Домашние задания курса Deep Agents

## Общие требования ко всем заданиям

- Язык: Python 3.12+
- Менеджер пакетов: `uv`
- Линтер: `ruff` (без ошибок)
- Типизация: `mypy` (без ошибок)
- Тесты: `pytest` (все проходят)
- Структура: `src/<package>/`, `tests/`, `pyproject.toml`, `README.md`
- Сдача: приватный GitHub-репозиторий, доступ для куратора

## ДЗ-01: LangChain Basics

**Тема:** Первый агент с тулами.

**Задание:**
Реализовать ReAct-агента, который умеет:
1. Отвечать на вопросы о погоде (mock-тул `get_weather`).
2. Конвертировать валюту (mock-тул `convert_currency`).

**Требования:**
- Агент использует `AgentExecutor` или `create_react_agent`.
- Тулы задокументированы через docstring.
- Минимум 2 unit-теста на каждый тул.

**Дедлайн:** 7 сентября, 23:59 МСК

## ДЗ-02: LangGraph StateGraph

**Тема:** Граф с памятью.

**Задание:**
Реализовать чат-бот на `StateGraph` с:
1. Узлом `chat` — вызов LLM.
2. Узлом `summarize` — сжатие истории при превышении 10 сообщений.
3. Условным переходом: `chat → summarize → chat`.

**Требования:**
- `InMemorySaver` для персистентности в рамках сессии.
- `stream_mode="updates"` в демо-скрипте.
- Тест на корректность работы summarize-перехода.

**Дедлайн:** 14 сентября, 23:59 МСК

## ДЗ-04: DeclarativeSubAgent

**Тема:** Dict-спека субагента с тулами.

**Задание:**
Реализовать `faq_agent` — субагент, отвечающий на вопросы по документации:
1. Тул `list_docs()` — список доступных документов.
2. Тул `read_doc(filename)` — чтение документа с защитой от path-traversal.
3. Dict-спека `FAQ_AGENT_SPEC` с `name`, `system_prompt`, `tools`.

**Требования:**
- `read_doc("../secret")` → `PermissionError`.
- 4 unit-теста (list, read, traversal, spec).
- Путь к файлам абсолютный (не зависит от cwd).

**Дедлайн:** 28 сентября, 23:59 МСК

## ДЗ-05: Handoffs

**Тема:** Переключение режимов через middleware.

**Задание:**
Реализовать `AssistantAgent` с тремя режимами:
1. `general` — общие вопросы.
2. `code` — помощь с кодом.
3. `review` — ревью кода.

Тулы-переходы: `switch_to_code`, `switch_to_review`, `return_to_general`.

**Требования:**
- Middleware оборачивает вызов модели.
- История диалога едина при смене режимов.
- Тег `[mode: code]` в стриминге при переключении.
- Тесты переходов `general → code → review → general`.

**Дедлайн:** 5 октября, 23:59 МСК

## ДЗ-06: Router

**Тема:** LLM-классификатор интента.

**Задание:**
Реализовать `IntentRouter`:
1. `Intent` — Pydantic-модель с `Literal["general", "code", "review", "stay"]`.
2. Sticky-логика: Router видит текущий режим и хвост диалога (3 сообщения).
3. Fail-safe: сбой LLM → `stay`.

**Требования:**
- Structured output через `with_structured_output`.
- Unit-тесты с mock LLM (3+ сценария).
- Тег `[router]` в стриминге.

**Дедлайн:** 12 октября, 23:59 МСК
