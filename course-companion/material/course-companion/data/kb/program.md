# Программа курса «Deep Agents: продвинутая разработка ИИ-агентов»

Курс о production-ready агентных системах: от AI-driven проектирования до масштабирования —
через GraphRAG, Deep Agents, evaluation и протоколы A2A/A2UI.

**Формат:** 12 занятий · ~1,5 месяца · 12 заданий · доступ к материалам 1 год · онлайн.
**Эксперт:** Сергей Смирнов (к.т.н., руководитель лаборатории AIRnD.ru).

## Темы

**Тема 1. AI-driven проектирование агентской системы.**
Обзор ключевых концепций production-ready агентских систем, базовые компоненты, MCP, HITL,
AI-driven проектирование спецификации.

**Тема 2. AI-кодинг production-ready агента.**
Настройка кодового агента, контекст для AI-кодинга, правила и соглашения,
AI-driven разработка ИИ-агента по спецификации.

**Тема 3. Датасет менеджмент.**
Анализ исходных данных, синтез валидационных датасетов, annotation queues,
управление датасетами.

**Тема 4. Векторные базы данных.**
Архитектура векторных БД, индексация и алгоритмы поиска, фильтрация,
интеграция в агентную систему.

**Тема 5. Графовые базы данных и GraphRAG.**
Графовые БД для Knowledge Graphs, гибридный поиск, GraphRAG для улучшения RAG.

**Тема 6. Мультимодальный RAG.**
Работа с визуально-насыщенными документами, таблицами, диаграммами,
интеграция мультимодальности в RAG.

**Тема 7. Продвинутый context-engineering.**
Управление контекстом через State, Store, файловую систему, MCP, dynamic context.

**Тема 8. Deep Agents: планирование и делегирование.**
Planning, task decomposition, Skills, Subagents, Long-term memory, Checkpoint и Resume.

**Тема 9. Evaluation и Red teaming.**
Component-level evaluation через tracing, метрики для агентов, DeepEval, RAGAS,
red teaming, adversarial attacks.

**Тема 10. Prompt Management.**
Централизованное управление промптами, версионирование, Prompt Playground, MCP,
link to traces, A/B testing.

**Тема 11. Мультиагентные паттерны.**
Паттерны мультиагентных систем: Subagents, Handoffs, Router, Custom workflows.

**Тема 12. Масштабирование агентных систем.**
Асинхронная коммуникация, распределённые системы, Agent-to-Agent (A2A),
Agent-to-UI (A2UI).
