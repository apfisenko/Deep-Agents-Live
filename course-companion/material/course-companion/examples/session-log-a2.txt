### В чём суть рекомендации?
В проекте отлично реализована модульная структура, обработка ошибок и контекстный менеджер для отображения прогресса (`LiveProgress` в `progress.py`). Чтобы гарантировать стабильность работы CLI при его дальнейшем расширении, рекомендуется покрыть эти модули юнит-тестами.

### Как это реализовать?

1. **Тестирование CLI-команд (`main.py`):**
   Для тестирования CLI на базе библиотеки `Typer` отлично подходит `typer.testing.CliRunner`.
   Пример теста:
   ```python
   from typer.testing import CliRunner
   from main import app

   runner = CliRunner()

   def test_cli_help():
       result = runner.invoke(app, ["--help"])
       assert result.exit_code == 0
       assert "Show this message and exit" in result.output
   ```

2. **Тестирование контекстного менеджера (`progress.py`):**
   Можно протестировать, что `LiveProgress` корректно обрабатывает фазы и не падает при возникновении исключений внутри контекста:
   ```python
   import pytest
   from progress import LiveProgress

   def test_live_progress_context():
       with LiveProgress() as progress:
           progress.update("test_phase")
           # Проверяем, что состояние обновилось корректно
   ```
