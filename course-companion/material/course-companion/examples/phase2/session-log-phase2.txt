Живые прогоны фазы 2 «проверка фоновая, чекер — отдельный сервис» (2026-07-10)
==============================================================================

Модель: google/gemini-3.5-flash через OpenRouter; LangSmith-ключ НЕ задан.
Браузер: Playwright, localhost:5173 (Vite слушает ::1 — ходим на localhost).

Конфигурации
------------
co-deployed (ступень 2): оба графа в одном langgraph.json, один сервер
    uv run langgraph dev --no-reload --no-browser --n-jobs-per-worker 10   # :2024
    cd frontend && npm run dev                                             # :5173

распил (ступень 3): те же графы, та же кодовая база — другой конфиг + env
    uv run langgraph dev --config langgraph.checker.json --port 2025 \
        --no-reload --no-browser --n-jobs-per-worker 10                    # :2025
    CHECKER_URL=http://localhost:2025 uv run langgraph dev --no-reload \
        --no-browser --n-jobs-per-worker 10                                # :2024
    cd frontend && CHECKER_PROXY_TARGET=http://127.0.0.1:2025 npm run dev  # :5173

Код companion/checker байт-в-байт общий: переход 2→3 = второй конфиг-файл
+ две env-переменные (CHECKER_URL серверу, CHECKER_PROXY_TARGET фронту).

3. Steering и cancel (логи steering-codeployed.txt, cancel-codeployed.txt)
--------------------------------------------------------------------------
steering: инструкция «строго по PEP8 + слово БАНАН» дослана на 20-й секунде →
  update_async_task: НОВЫЙ run_id на том же треде, старый ран — interrupted
  (перезапуск проверки с полной историей, время удваивается — честно
  предупреждает и сам companion); финальный вердикт учёл инструкцию.
cancel: отмена на 15-й секунде → у companion задача cancelled, на сервере
  чекера тот же ран — interrupted: статусы РАСХОДЯТСЯ на шве, в UI маппинг
  «перебита (отмена или новая инструкция)».

Постскриптум (фиксы по ревью)
-----------------------------
- Распил получил собственный конфиг companion-сервера (langgraph.companion.json):
  на :2024 остаётся только граф companion — граница сервисов совпадает с
  границей деплоя буквально (санити-лог remote-clean-configs.txt).
- Поллер дедуплицирует авто-сообщения через историю треда (переживает
  перезагрузку страницы); упавший ран больше не рисует ✓ на незавершённых
  tool-вызовах.
- Оговорка про статусы на шве: адаптер чекера сознательно превращает ошибки
  пайплайна в текстовый вердикт «Проверка не удалась» (ран НЕ падает) — статус
  error на сервере чекера в этом сценарии не возникает; error-ветки UI
  срабатывают на инфраструктурных отказах (упавший сервер, оборванный ран).
