# Course Companion

---

## Суть продукта

Course Companion — диалоговый ассистент студента курса Deep Agents. В едином чат-интерфейсе студент задаёт вопросы по программе курса, сдаёт домашнее задание и разбирает полученный фидбек. Пользователь видит одного собеседника — за сценой работает пайплайн субагентов. Course Companion — это не учебный тренажёр и не платформа: это CLI-ассистент, живущий рядом с кодом студента.

---

## Для кого

- **Студент курса Deep Agents** — получает ответы по программе курса и сдаёт домашние задания прямо из терминала, без переключения контекста.
- **Преподаватель / автор курса** — получает демонстрационную систему, которая показывает все пять мультиагентных паттернов LangChain в одном живом продукте.

---

## Какую задачу решает

Студент курса сталкивается с двумя трениями в разные моменты работы: «не понимаю, как устроен курс / что нужно сдать» и «получил фидбек на ДЗ, но не понимаю, что именно исправить». До Course Companion оба вопроса решаются вне кода — через чаты, страницы курса, ручную интерпретацию отчёта ментора. Course Companion убирает переключение контекста: и справка по курсу, и сдача ДЗ с разбором — в одном терминальном чате.

---

## Что в первой очереди (MVP)

- Ответы на вопросы по курсу (расписание, программа, формат, FAQ) по базе знаний из md-файлов.
- Приём кода домашнего задания (путь + тема) и запуск проверки через `ai-homework-mentor`.
- Разбор фидбека: объяснение замечаний, ответы на уточняющие вопросы студента по итогам проверки.
- Возврат к режиму вопросов по курсу после завершения разбора.
- Dogfooding: сдача самого `course-companion/` по рубрике `multi-agent` — система проверяет сама себя.
