# Gaps после Sprint 00 (skeleton)

> Зафиксировано: 2026-07-24. Это ещё **не** проверка домашних заданий.

## Что уже есть

- Запуск через `make.ps1` (sync / run / lint / format / test)
- Rich CLI: `-Message` / `-Path` / `-Verbose`
- DeepAgents + OpenRouter: простой ответ на сообщение
- Промпты и параметры модели в YAML
- Логирование с redaction секретов

## Чего намеренно нет (боль для следующих спринтов)

| Gap | Почему больно | Когда закрываем |
|-----|---------------|-----------------|
| Нет разбора входа (тема / GitHub URL) | Агент отвечает «в воздух», не знает *что* проверять | **S1** |
| Нет чтения дерева кода / clone репо | Нельзя опереться на файлы студента | **S1** |
| Нет workspace / rubric / todo-плана | Нет наблюдаемого процесса проверки и артефактов | **S2** |
| Нет видимого context engineering | Не видно роста окна и компактизации | **S3** |
| Нет reviewer-субагентов | Нет изоляции аспектов проверки | **S4** |
| Нет skills / rubric-skills | Критерии не переиспользуются | **S5** |
| Нет синтеза `final_feedback` / `fix_plan` | Нет actionable итога по rubric | **S6** |
| Нет dogfooding на себя | Нет доказательства сквозной зрелости | **S7** |

## Verbose в S0 — только заготовка

В `-Verbose` показываем модель / режим / путь к YAML-промпту.  
**Не** показываем: todo, дерево workspace, субагентов, токены/CE — их ещё нет.
